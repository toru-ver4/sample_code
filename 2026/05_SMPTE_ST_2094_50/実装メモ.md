# SMPTE ST 2094-50 実装メモ

## 定義の再確認

### 用語整理

* HDR reference white: 基準となる白色の輝度。cd/㎡ で定義
  * 基本は 203 nits
  * 後述の relative linear color space への変換（正規化）で使われる
* relative linear color space: 3刺激値 (1, 1, 1) が HDR reference white を示す線形の色空間
* gain application color space: color gain function を適用する空間。
  * relative linear color space から 3x3 Matrix で変換した色空間（理論上は XYZ も行けるはず…？）

### 基本パラメータと制約

* L_white: HDR reference white
  * 範囲は (0, 10000]
* C: 入力の三刺激値
* H_baseline: baseline HDR headroom
  * 範囲は [0, 6]
* N_alt: alternate images の数
  * 0以上4以下の整数
* H_alt,i: alternate HDR headroom。i は N_alt の範囲
  * 範囲は H_baseline と同様に [0, 6]
  * H_alt,i と H_baseline が同じ値を取ることは禁止
  * H_alt,i は index i に対して昇順 (0 <= i <= N_alt-1 に対して H_alt,i < H_alt,i+1) であること
* χ_red, χ_green, χ_blue, χ_white: gain application color space の xy色度座標
  * 範囲は [0, 1]
* Gain_alt,i: alternate image を作るための color gain function
  * color gain function structures は Gain_alt,i を定義する？
  * 詳細は後述
* GainCurve_i(x): Gain を計算するための関数
  * ここで x は relative linear color space の値
    * 例えば x=2.0 で ref white 203 nits だったら、実際の輝度は 406 nits
  * 出力は log2 な Gain 値
    * Gain = 1.0 なら元の信号を 2倍にする、Gain = -1.0 なら元の信号を 0.5倍にする
* N_cp: control points の数
* x_i: gain application color space での値。GainCurve の入力となる値
  * 範囲は [0, 64]
* y_i: GainCurve の出力となる値
  * 範囲は [-6, 6]
* m_i: GainCurve の入力となる値。たぶん傾きを示している
